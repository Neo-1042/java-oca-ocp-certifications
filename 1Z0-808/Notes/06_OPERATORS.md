# Operators in Java

We have three main types:

1. Unary Operators (e.g. `a++`)
2. Binary Operators (e.g. `x*y`)
3. Ternary Operator  
`a = ( b >= 0 ) ? 3 : -3; `

## Operator Precedence

(i) Unary operators go first, then  
(ii) Binary mathematical operators  
(iii) Relational and logical operators  
(iv) Ternary Operator  
(v) Assignment Operator  
(vi) Arrow Operator (`->`)
